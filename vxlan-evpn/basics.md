# EVPN Basics

## What is EVPN?

EVPN (Ethernet VPN) is a BGP control-plane technology used to distribute MAC and IP reachability information across a VXLAN fabric.

## Why EVPN?

- Control-plane MAC learning (no flooding)
- Scalable multi-tenant segmentation
- Supports L2 and L3 services
- Enables Anycast Gateway
- Supports multi-homing (ESI)

## Key Concepts

- BGP EVPN Address Families
- Route Types (RT2, RT3, RT5)
- VNI (L2VNI / L3VNI)
- MAC/IP Advertisement
- ARP suppression
